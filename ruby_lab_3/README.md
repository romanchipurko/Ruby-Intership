# Task 3
## Brute Force
Brute Force на тесте из 20000 объектов (значения от -100000 до 100000) и случайным таргетом (сумма последний двух элементов матрицы, для лучшего ислледования времени) показал результаты:
```
Target: 65210
First: 4824
Second: 60386
Result: [18, 12308]

Brute Force time: 0.0009735820003697881
```

Метод работает за `O(n^2)` по времени, `O(1)` по памяти.

## Hash Map
Hash Map на тесте из 20000 объектов (значения от -100000 до 100000) и случайным таргетом (сумма последний двух элементов матрицы, для лучшего ислледования времени) показал результаты:
```
Target: 65210
First: -9076
Second: 74286
Result: [755, 616]

Hash Map time: 0.00011873400035256054
```

Метод работает за `O(n)` по времени, но и `O(n)` по памяти.

### Вывод
Выигрыш по времени у второго метода в 8 раз лучше. Таким образом, Hash Map является лучшим методом для решения этой задачи засчет лучшего алгоритма (`O(n)` против`O(n^2)`).
